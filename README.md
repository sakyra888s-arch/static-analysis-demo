Описание проекта
Данный репозиторий представляет собой демонстрационную информационную систему, реализующую конвейер непрерывной интеграции (CI) со статическим анализом кода. 

Главная цель: Автоматическая проверка качества кода при каждом изменении и блокировка слияния (Merge) при наличии критичных замечаний.

Стек технологий и архитектура:
*   ESLint и Prettier — линтеры для проверки синтаксиса, поиска ошибок (неиспользуемых переменных) и форматирования.
*   SonarQube — платформа для глубокого статического анализа (Security, Reliability, Maintainability), развернутая локально в Docker.
*   GitHub Actions — облачный CI-пайплайн, который автоматически запускает проверки при `push`.
*   Tuna — туннель, обеспечивающий безопасную связь между облачным GitHub и локальным SonarQube.

Как работает пайплайн:
1. Разработчик вносит изменения в код и делает `git push`.
2. GitHub Actions автоматически запускает воркфлоу.
3. Шаг 1: Устанавливаются зависимости (`npm install`).
4. Шаг 2: Запускается ESLint (`npm run lint`). При наличии ошибок пайплайн падает.
5. Шаг 3: Выполняется сканирование SonarQube. Анализируются метрики и уязвимости.
6. Шаг 4: Проверка Quality Gate. Если анализ не пройден — слияние (Merge) блокируется.

Результаты работы
*   Настроена блокировка мержа (Branch Protection Rules) при падении проверок.
*   Исправлены ошибки в коде (`app.js`) для успешного прохождения проверок.
*   Интегрирован локальный сервер с облачным CI через HTTPS-туннель.
